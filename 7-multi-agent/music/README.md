# Soundtrack for the trip film

Drop one audio file here (`.mp3`, `.m4a`, `.aac` or `.wav`) and the trip
video will be scored with it, faded out at the end. The first file in
alphabetical order is used.

**Nothing is included here on purpose.** The video is built to be shared, so
the track has to be one you hold redistribution rights to. A one-off
royalty-free licence (Epidemic Sound, Artlist, Uppbeat and similar) covers
this; music taken from YouTube or Spotify does not, and the rights-holders
for music are considerably more litigious than those for photographs.

Two or three tracks of different moods, selected by trip type, would be a
reasonable next step — the picker would go in `export_itinerary`.
